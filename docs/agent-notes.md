# AI エージェント側への申し送り事項

このリポジトリ（Web UI + MCP サーバー）の実装中に判明した、AI エージェント側で対応が必要な事項を記録する。

## フォーマット

```
### US-XXX: ストーリー名

- [ ] 対応事項の内容
```

### US-001: AIによる翌日のタスク提案

#### タスク提案のワークフロー

AIエージェントが翌日のタスクを提案する際は、以下の手順で MCP ツールを呼び出す。

1. `list_tasks` で未完了タスク（`statuses: ["not_started", "in_progress"]`）を取得する
2. `list_daily_reports` で翌日の日報が存在するか確認する
3. 翌日の日報が存在しない場合は `create_daily_report` で作成する
4. 提案するタスクごとに `create_task` で作成し、`dailyReportId` に翌日の日報IDを指定する
5. `reorder_tasks` で提案するタスクの優先順位を設定する（配列の先頭が最も優先度が高い）

#### フィードバック対応の手順

ユーザーからフィードバックを受けて再提案する際は、以下の手順で対応する。

1. `list_tasks` で翌日の日報に紐づくタスク（`dailyReportId` で絞り込み）を取得する
2. 不要なタスクは `delete_task` で削除する
3. 変更が必要なタスクは `update_task` で更新する
4. 新しいタスクは `create_task` で追加する
5. `reorder_tasks` で並び順を再設定する
