# US-008: AIによるプロジェクト作成支援

## 受け入れ条件と実装タスクの対応

| 受け入れ条件 | タスク |
|---|---|
| AI がプロジェクト作成のための質問を開始できる | タスク1 |
| AI が利用者の回答をもとにプロジェクトの内容を提案できる | タスク1 |
| 利用者がフィードバック・手動編集で内容を修正できる | 実装済み |
| 利用者が確定するとプロジェクトが DB に保存される | 実装済み |
| タスクをプロジェクトに紐づけられる | 実装済み |
| プロジェクトに属さないタスクも作成できる | 実装済み |
| ダッシュボードにプロジェクト一覧が表示される（US-010） | タスク2 |

## タスク

### タスク1: MCP プロジェクトツールの追加

- **種別**: `/add-backend`
- **DB マイグレーション**: なし
- **詳細**: `src/mcp/tools/project.ts` に以下の5ツールを追加し、`src/mcp/server.ts` に登録する
  - `list_projects` - プロジェクト一覧取得（`getProjectsUseCase`）
  - `get_project` - プロジェクト詳細取得（`getProjectUseCase`）
  - `create_project` - プロジェクト作成（`createProjectUseCase`）
  - `update_project` - プロジェクト更新（`updateProjectUseCase`）
  - `update_project_status` - ステータス変更（`updateProjectStatusUseCase`）
  - 既存の `src/mcp/tools/task.ts` のパターンに従い、UseCase を呼び出すだけの薄いラッパーとして実装する
  - DI コンテナ（`src/server/infrastructure/di/container.ts`）から UseCase を import する

### タスク2: ダッシュボードにプロジェクト一覧を表示する

- **種別**: `/add-frontend`
- **DB マイグレーション**: なし
- **詳細**: ダッシュボード（`src/app/_components/dashboard.tsx`）にプロジェクト一覧セクションを追加する
  - `trpc.project.list` でプロジェクト一覧を取得する
  - プロジェクト名・ステータス・期限を表示する
  - 各プロジェクトから詳細ページ（`ROUTES.projectDetail(id)`）へ遷移できるリンクを設置する
  - 既存のプロジェクト一覧ページ（`src/app/projects/_components/project-list.tsx`）のデザインを参考にする
  - E2E テスト（`e2e/dashboard.test.ts`）にプロジェクト表示のテストケースを追加する
