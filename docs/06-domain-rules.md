# ドメインルール

## タイムゾーン

- DB・サーバは UTC で保存・処理する
- クライアントは JST（Asia/Tokyo）で表示する
- 日付の境界は JST の 0:00（= UTC 15:00 前日）を基準とする

## カレンダー

- 週は**月曜日**に始まる

## レポートの期間

- **日報**: 1日単位。同じ日付の日報は1つだけ作成できる
- **週報**: startDate から7日間。週報に属する日報は startDate（月曜日）から7日間に含まれる日報である
- **月報**: 月の1日から月末まで。月報に属する週報は、startDate（月曜日）がその月に含まれる週報である

## タスク

- ステータスは `not_started | in_progress | done | cancelled | deferred` の5つである
- ステータス遷移に制約はなく、どの状態からどの状態へも遷移できる
- `sortOrder` はその日のタスクの優先順位を示す。値が小さいほど優先度が高い
- 繰り越し（「今度やる」）時の挙動:
  - その日に完了しなかったタスク（`not_started` または `in_progress`）を複製し、`not_started` の新しいタスクを作成する
  - 複製元のタスクは `deferred` にする
  - 複製先のタスクは複製元への参照（`carriedOverFromId`）を持つ
